🌐 LLM Conversation Navigator

A browser extension for ChatGPT / Gemini / Claude / DeepSeek that allows quick navigation of your historical questions.

📘 Overview

When chatting with LLMs like ChatGPT, Gemini, Claude, or DeepSeek, long conversations often become hard to navigate.
This extension adds a small floating “Q” button on supported LLM websites that:

Automatically captures your questions in the conversation

Displays them in a side panel

Allows one-click jump to any previous question

Automatically resets when switching to a new conversation

Works across multiple LLM platforms without manual configuration

This tool is designed to enhance productivity and reduce the frustration of scrolling endlessly to find past queries.
